# Nova AI – An Intelligent Productivity Assistant

## About the Project

Nova AI is a web-based intelligent productivity assistant developed as a college project. It combines AI-powered assistance and productivity management features in one application.

## Features

* AI Chat Assistant
* Voice Assistant with speech recognition and speech synthesis
* Smart Notes with search and AI summarization
* To-Do Manager
* Reminder Manager with notifications
* Study Planner
* PDF Chat and Summarization
* Resume Analyzer
* AI Email Writer for generating email content
* Dashboard and Unified Search
* User authentication and profile management
* Supported cross-module AI actions

## Technology Stack

* **Frontend:** React, Vite, JavaScript, HTML and CSS
* **Backend:** Node.js and Express.js
* **Database:** MongoDB and Mongoose
* **AI Integration:** Google Gemini API
* **Authentication:** JWT and bcrypt
* **Other Technologies:** Web Speech API, Web Push, node-cron and Nodemailer

## Prerequisites

Before running the project, install:

* Node.js and npm
* Git
* MongoDB, either locally or through MongoDB Atlas
* The required API credentials and configuration for the integrated services

## Installation and Setup

1. Clone this repository.
2. Install the dependencies in the frontend and backend directories.
3. Configure the backend environment variables in a local `.env` file.
4. Configure MongoDB and the required AI and email service credentials.
5. Start the backend and frontend using the commands documented in their respective directories.
6. Open the frontend in your browser at `http://localhost:5173`.

Refer to the setup instructions below once the exact folder structure, scripts and environment variables have been verified.

## Security

Do not commit real API keys, database credentials, email app passwords, JWT secrets or other sensitive information to GitHub. Keep environment variables in local `.env` files and use placeholders in any example configuration.
